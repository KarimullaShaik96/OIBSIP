# Unemployment Analysis with Python 📊

## OASIS INFOBYTE - Data Science Task 2

### 📌 Project Overview

This project analyzes unemployment trends in India using Python and
exploratory data analysis techniques.

The analysis focuses on regional unemployment patterns, monthly trends,
employment indicators, and changes during the COVID-19 period.

### 🎯 Objective

The objective of this project is to analyze unemployment data and identify
important regional and temporal patterns, particularly around the COVID-19
period.

### 🛠️ Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

### 📂 Dataset

The project uses the **Unemployment in India** dataset.

The dataset contains information including:

- Region
- Date
- Frequency
- Estimated Unemployment Rate
- Estimated Employed
- Estimated Labour Participation Rate
- Area

### 🔍 Analysis Performed

The project includes:

1. Data loading and inspection
2. Missing-value analysis
3. Data cleaning
4. Date conversion
5. Region-wise average unemployment analysis
6. Monthly unemployment trend analysis
7. Comparison of unemployment trends across three regions
8. Top 10 regions by average unemployment
9. Correlation heatmap of employment indicators
10. Pre-COVID vs COVID-period comparison

### 📈 Visualizations

The notebook contains:

- Regional unemployment bar chart
- Monthly unemployment line chart
- Three-region comparison line chart
- Top 10 regions bar chart
- Correlation heatmap
- Pre-COVID vs COVID-period comparison chart

### 🧠 Key Findings

The analysis demonstrates that unemployment rates vary across regions and
change over time.

The comparison between the pre-COVID and COVID periods helps illustrate
changes in unemployment conditions during the pandemic.
