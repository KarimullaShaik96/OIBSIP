# OIBSIP Web Development - Task 5

## 📝 To-Do App

A simple and responsive To-Do application developed using HTML, CSS, and JavaScript.

## 🎯 Objective

To create an interactive task management application that allows users to add, complete, and delete tasks.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ✨ Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Clear completed tasks
- Task counter
- Enter key support
- Input validation
- Responsive design
- Styled buttons with hover effects
