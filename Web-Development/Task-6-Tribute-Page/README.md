# OIBSIP Web Development - Task 6

## 🏆 Tribute Page

A responsive tribute webpage dedicated to **Dr. A. P. J. Abdul Kalam**, highlighting his life, achievements, contributions, and legacy.

## 🎯 Objective

To design and develop a visually appealing and responsive tribute page using HTML5 and CSS3.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Responsive Web Design

## ✨ Features

- Hero section with name and tagline
- Prominent image
- Introduction section
- Biography and important contributions
- Timeline of major achievements
- Inspirational quote section
- Legacy section
- Responsive design for mobile devices
- Multiple background colors and font styles
- Clean and structured layout
