# OIBSIP Web Development Task 1 - Landing Page

## Project Overview

SkillTrendX is a modern landing page concept for an AI-powered career and skill analysis platform.

The landing page presents the platform's main features, career analysis capabilities, skill gap analysis, AI career prediction, and learning roadmap.

## Objective

The objective of this project is to create a visually appealing and responsive static landing page using HTML5 and CSS3.

## Features

- Sticky navigation bar
- Hero section with call-to-action
- AI career analysis preview
- Skill analysis visualization
- Feature cards
- About section
- Career statistics
- Call-to-action section
- Responsive mobile layout
- Clean and modern user interface
- Footer with contact and social links

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive Web Design
