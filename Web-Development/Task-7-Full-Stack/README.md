# 📝 Full Stack Task Manager

A simple full-stack Task Manager application developed using HTML, CSS, JavaScript, Python Flask, and SQLite.

## 🎯 Objective

To develop a full-stack web application where users can create, view, complete, and delete tasks using a frontend connected to a backend API and database.

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Python
- Flask
- Flask-CORS

### Database
- SQLite

## ✨ Features

- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Input validation
- REST API integration
- SQLite database storage
- Responsive user interface
- Frontend and backend communication using Fetch API
