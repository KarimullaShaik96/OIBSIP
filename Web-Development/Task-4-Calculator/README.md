# OIBSIP Web Development - Task 4

## 🧮 Calculator

This project is a simple and responsive calculator developed using HTML, CSS, and JavaScript.

## 🎯 Objective

To create a functional calculator that performs basic arithmetic operations through an interactive web interface.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ✨ Features

- Addition
- Subtraction
- Multiplication
- Division
- Percentage
- Decimal calculations
- Clear button
- Delete button
- Error handling
- Responsive design
