# OIBSIP Python Programming Task 3 - Random Password Generator

## Project Overview

This project is a Random Password Generator developed using Python.

The program generates a strong random password based on the length provided by the user.

## Features

- Generates random passwords
- Supports uppercase and lowercase letters
- Includes numbers
- Includes special characters
- Allows the user to choose password length
- Validates the password length
- Uses Python's secure `secrets` module

## Technologies Used

- Python
- Standard Python libraries
