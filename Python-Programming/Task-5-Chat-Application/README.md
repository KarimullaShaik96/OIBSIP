# Chat Application

## Project Overview

This project is a simple client-server chat application developed using Python socket programming.

The application allows multiple clients to connect to a central server and exchange messages in real time.

## Objective

To develop a basic network-based chat application using Python sockets and multithreading.

## Technologies Used

- Python
- Socket Programming
- TCP/IP
- Multithreading
